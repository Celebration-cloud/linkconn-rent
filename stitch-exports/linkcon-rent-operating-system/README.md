# Linkcon Rent Operating System — Stitch Export

Source project: `14431731746230511822`

This directory contains the requested Stitch output:

- `code/`: generated HTML for every screen that exposes code
- `images/`: full-resolution Stitch screenshots
- `design-system/DESIGN.md`: the Stitch design-system source
- `manifest.json`: screen IDs, dimensions, titles, and hosted source URLs

The Linkcon Rent Logo is an image-only Stitch screen, so it has no HTML file.
The Design System is an asset instance rather than a screen; its source is stored
as `design-system/DESIGN.md`.
